# GDrive-Link-Converter
Sebuah aplikasi web berbasis instan dan minimalis untuk mengubah tautan berbagi Google Drive menjadi tautan gambar langsung (Direct Link &amp; Thumbnail Avatar). Cukup tempel tautan, konversi, dan salin URL modifikasi yang siap digunakan langsung pada tag gambar HTML atau dasbor CMS Anda.

Fitur Utama (Key Features):

Instant ID Extraction: Otomatis mendeteksi dan mengambil ID file unik dari berbagai format URL Google Drive.

Dual Output Format: Menyediakan format resolusi asli (Direct View) dan format kotak proporsional (Thumbnail Avatar 1:1).

One-Click Copy: Menyalin hasil konversi secara cepat ke clipboard dengan indikator visual.

Live Circular Preview: Menampilkan pratinjau instan dalam bentuk avatar bulat untuk memastikan gambar termuat dengan benar sebelum digunakan.
