# GDrive-Link-Converter
Sebuah aplikasi web berbasis instan dan minimalis untuk mengubah tautan berbagi Google Drive menjadi tautan gambar langsung (Direct Link &amp; Thumbnail Avatar). Cukup tempel tautan, konversi, dan salin URL modifikasi yang siap digunakan langsung pada tag gambar HTML atau dasbor CMS Anda.
